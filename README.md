# ☕ Kopi dan Nyemil

> *Sipping happiness, one cup at a time*

Aplikasi mobile berbasis Android untuk pemesanan kopi, makanan ringan, dan jajanan kafe secara praktis. Proyek ini dikembangkan menggunakan **Java** dan **XML** di **Android Studio** sebagai pemenuhan tugas mata kuliah Pengembangan Aplikasi Mobile.

---

## ✨ Fitur Utama
* **Splash & Welcome Screen**: Tampilan awal estetik bernuansa kafe yang menyambut pengguna.
* **Autentikasi Pengguna**: Halaman Login dan Register dengan desain modern dan responsif.
* **Katalog Menu Favorit**: Menampilkan daftar menu makanan dan minuman lengkap dengan foto dan harga.
* **Keranjang & Checkout**: Fitur untuk mengelola pesanan, memilih metode pembayaran (COD, E-Wallet, Transfer Bank), serta mengisi alamat pengiriman.
* **Struk Pembayaran**: Halaman konfirmasi sukses pesanan yang merangkum rincian transaksi secara otomatis.
* **Profil Pengguna**: Pengelolaan data profil, riwayat pesanan, dan pengaturan preferensi akun.

---

## 🛠️ Teknologi & Tools
* **Bahasa Pemrograman**: Java
* **UI Layout**: XML (RelativeLayout, LinearLayout, CardView, ConstraintLayout)
* **IDE**: Android Studio
* **Version Control**: Git & GitHub
